About WebGuard

WebGuard is an educational, passive, non-destructive web security assessment platform built as a college cybersecurity project.

What it checks
  • URL validity, reachability, status, redirects, response time
  • Six security response headers
  • Cookie Secure / HttpOnly / SameSite attributes
  • HTTPS use, TLS version, certificate expiry
  • Server / X-Powered-By disclosure
What it does NOT check
  • SQL injection, XSS or any exploitation
  • Brute force, credentials, DoS, directory brute forcing
  • Page content, JavaScript, forms, authenticated areas
  • Full OWASP Top 10 coverage
Authorized use policy: only scan websites you own or have explicit permission to test. Private/loopback addresses are blocked by default.

Future development: PDF export, deeper TLS analysis, scheduled scans.
